# ygbPort/
> L2 | 父级: ../CLAUDE.md

云柜宝港区 Canvas 引擎：正交二测视角下的集装箱码头全景。框架无关，唯一入口 index.js；正式 Hero 经 react/pages/ReactYgbPortBackground 挂载，ygb-hero-prototype.html 直接挂载用于调试，二者只调用 mountYgbPort。

成员清单
index.js: 唯一入口 mountYgbPort(canvas,{dark,paused})，返回 setTheme/setPaused/setSpeed/flyTo/subscribe/dispose 与 scene；转出五个配图 mount。
scene.js: 总装与渲染调度，画布生命周期、静态烘焙 (按最小动态深度决定烘焙或精灵)、精灵图集、整层阴影一次模糊、船体分段精灵、夜间光照图 (白天仅重建时临时分配)、镜头锚点与 flyTo 覆盖镜头飞行 (途中 CSS 缩放一张覆盖起终点的渲染、快照交叉淡化两端且淡出后释放显存、被打断时从屏幕实际视图续飞)、帧订阅与事件总线 (scene.on)、画质档位 (静止保持像素比 2；飞行途中临时 1.5 (仅约 250 万物理像素以上的大舞台，小屏省掉这次额外重建)；静止帧耗时持续超 20ms 则本次会话降到 1.5) 以及全部分层顺序。
iso.js: 投影与绘制原语 (盒体/有向盒/棱柱/缓存光斑印章)、色彩推导与 SUN/faceShade 光照约定，所有模块共用。
palette.js: 昼夜材质表与集装箱/车辆配色索引；物件只存索引，换主题不换布局。
layout.js: 空间宪法，岸线/轨道/车道/堆场行列/街网/闸口/船位/岸桥坐标与城市、堆场地块表。
roads.js: 交通拓扑，路段自动打断成节点、信号与让行判定、车辆线路、车道级路径 (路口弧线/换道/停止线/道闸)。
ground.js: 地面画家，海陆、港内铺装、公共道路标线与人行横道、码头前沿轨道与岸壁护舷，只画 z≈0。
structures.js: 建筑与街道家具工厂 (仓库/写字楼/住宅/控制塔/雨棚/储罐/树/路灯/高杆灯/围网/岗亭)，含白天投影与夜间灯池。
city.js: 城区编排，按街坊类型摆放物流园、集卡停车场 (右进右出道闸)、加油站、办公、公园与高层，以及行道树和路灯。
terminal.js: 港内编排，RTG 箱区按贝切块、空箱/冷藏区、闸口雨棚与道闸岗亭、查验通道、配套建筑与围网；导出 container 箱体绘制。
vehicles.js: 车辆外观库 (社会车/厢货/集卡/港内拖车/正面吊)，行驶与停放共用，夜间车灯光锥。
traffic.js: 交通动力学，发出 gate (闸口/停车场核验) 与 arrive (运单固定终点) 事件，跟驰、信号停车、港内让行、道闸核验、岸桥下停靠与离屏换箱；输出车辆/信号灯/道闸动态物件，追踪车辆的运单段 (固定终点) 与锚定到终点的规划路线。
ship.js: 靠泊集装箱船，外飘船首、驾驶台与烟囱、舱口盖与绑扎桥、逐箱箱格 (take/put)；按作业贝切成前后两段精灵。
cranes.js: 岸桥几何与 back/front/upper/hoist 分层绘制 (船体夹在门腿与大梁之间)；CraneWork 为唯一作业岸桥的逐贝装卸状态机。
sea.js: 海面动态，拖船/引航艇样条航线 (离屏加速)、开尔文尾迹、航道浮标、粼光与夜间倒影；导出 spline/at 样条工具。
figures/: 杂志配图状态源子模块 (7 文件)，订阅同一场景输出追踪/派单/运单链路/车队/监管上报状态，见 figures/CLAUDE.md。
sky.js: 顶层动态，低空直升机 (近距地影/旋翼/夜间航灯与探照灯)、海鸥、烟囱尾烟、预渲染云影与塔顶航标。

分层约定 (自后向前)：地面烘焙 → 岸桥投影/灯池 → 追踪路线/水面 → 陆域深度排序 → 前沿 (陆侧门腿 → 车辆/吊具 → 门框与海侧门腿) → 船体后段 → 海侧吊具 → 船体前段 → 夜间光照图 → 岸桥上部 → 海上船只 → 天空 → 环境光。
法则: 坐标只从 layout 取；绘制顺序只在 scene 定；动画状态按时间积分，不做正弦往返循环；重建路径禁止逐物件 ctx.filter；新增物件先问能否走已有工厂与静态物件契约。
